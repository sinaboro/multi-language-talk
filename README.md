# 여행 회화 한마디

해외여행에서 바로 쓰는 **115문장**을 **영어·일본어·중국어·이탈리아어·프랑스어** 5개 언어로 담은 모바일 앱입니다.
상황별 문장 보기, 한글 발음, 원어민 발음 듣기(TTS), 즐겨찾기, 퀴즈를 지원합니다.
폰에 설치하면 앱처럼 아이콘이 생기고, **인터넷 없이도** 쓸 수 있습니다.

**앱 주소:** https://sinaboro.github.io/multi-language-talk/

> 플레이스토어 앱이 아니라 웹 주소를 폰에 **설치**하는 방식(PWA)입니다.
> APK 파일을 받을 필요가 없고, 개인정보나 권한을 요구하지 않습니다.

---

## 가장 쉬운 설치 방법 (카카오톡)

**링크를 카카오톡으로 받아서 누르기만 하면 됩니다.**

```
https://sinaboro.github.io/multi-language-talk/
```

1. 카카오톡에서 위 링크를 누릅니다.
2. 앱이 **자동으로 Chrome(아이폰은 Safari)으로 넘어갑니다.**
   - 카카오톡 안의 브라우저는 앱 설치를 지원하지 않아서, 앱이 알아서 바깥 브라우저로 옮겨 줍니다.
   - 자동으로 넘어가지 않으면 화면 위쪽 초록색 안내의 **[Chrome으로 열기]** (아이폰은 **[Safari로 열기]**)를 누릅니다.
3. Chrome에서 열리면 화면 위쪽에 **"홈 화면에 앱으로 설치하면…"** 안내가 나옵니다. **[설치]** 를 누릅니다.
4. 확인 창에서 한 번 더 **설치**를 누르면 끝입니다.
   홈 화면(또는 앱스 화면)에 초록색 말풍선 **여행회화** 아이콘이 생깁니다.

> 아이폰은 3번에서 안내에 따라 Safari 아래쪽 **공유 버튼 → 홈 화면에 추가 → 추가**를 누릅니다.

## 1. 설치하기 전에

- **처음 설치할 때 한 번만** 인터넷(와이파이 또는 데이터)이 필요합니다.
- 갤럭시는 **Chrome**이나 **삼성 인터넷**, 아이폰은 **Safari**로 설치합니다.
  카카오톡·네이버·인스타그램 앱 안의 브라우저에서는 설치가 되지 않습니다. (앱이 바깥 브라우저로 옮기도록 안내합니다)
- 메뉴 이름은 폰 기종과 브라우저 버전에 따라 조금 다를 수 있습니다.
  (예: "앱 설치" / "홈 화면에 추가" / "설치")

## 2. 갤럭시 — Chrome으로 설치

1. Chrome에서 앱 주소를 엽니다.
2. 화면 위쪽에 초록색 **"홈 화면에 앱으로 설치하면…"** 안내가 보이면 **[설치]** 를 누르고 4번으로 갑니다.
   - 이 안내는 Chrome이 설치 준비를 마친 뒤 나타나므로 **몇 초** 걸릴 수 있습니다.
   - Chrome의 화면 아래쪽 설치 안내는 뜨지 않는 경우가 많습니다. 안 떠도 정상입니다.
3. 안내가 나오지 않으면 Chrome 오른쪽 위 **`⋮`** → **앱 설치**를 누릅니다.
   - 메뉴에 "앱 설치"가 없고 **홈 화면에 추가**만 있다면 그것을 누른 뒤 **설치**를 고릅니다.
4. 확인 창에서 **설치**를 누릅니다.
5. 홈 화면 또는 앱스 화면(화면을 위로 밀면 나오는 앱 목록)에 **여행회화** 아이콘이 생깁니다.
   길게 눌러 원하는 곳으로 옮길 수 있습니다.

## 3. 갤럭시 — 삼성 인터넷으로 설치

1. 삼성 인터넷에서 앱 주소를 엽니다.
2. 주소창 오른쪽에 **설치 아이콘(아래 화살표가 있는 모양)** 이 보이면 누르고 **설치**를 누릅니다.
3. 아이콘이 없으면 화면 아래 **`≡` (메뉴)** → **현재 페이지 추가** → **홈 화면**을 누릅니다.
4. 이름이 "여행회화"로 나오면 그대로 **추가**를 누릅니다.

## 4. 아이폰·아이패드 — Safari로 설치

1. 카카오톡에서 링크를 누르면 Safari로 넘어갑니다.
   넘어가지 않으면 위쪽 안내의 **[Safari로 열기]**, 또는 오른쪽 아래 `⋯` → **Safari로 열기**를 누릅니다.
2. Safari 아래쪽(아이패드는 위쪽)의 **공유 버튼(네모에서 위쪽 화살표)** 을 누릅니다.
3. 목록을 위로 밀어 **홈 화면에 추가**를 누릅니다.
4. 오른쪽 위 **추가**를 누릅니다.

> 아이폰은 Chrome에서는 설치되지 않습니다. 반드시 Safari를 쓰세요.

## 5. PC(윈도우)에서 설치

1. Chrome 또는 Edge에서 앱 주소를 엽니다.
2. 위쪽 초록색 안내의 **[설치]**, 또는 주소창 오른쪽 끝 **설치 아이콘**을 누릅니다.
   - Edge는 `⋯` → **앱** → **이 사이트를 앱으로 설치**
3. 시작 메뉴에 "여행 회화 한마디"가 생깁니다.

## 6. 설치가 잘 됐는지 확인하기

- 아이콘으로 실행했을 때 **주소창 없이 전체 화면**으로 열리면 앱으로 설치된 것입니다.
- 설치한 뒤 인터넷이 연결된 상태로 **한 번 앱을 열어** 두세요. 그다음에는 **비행기 탑승 모드**에서도 열립니다.

## 7. 여행 전에 꼭 해 둘 것

발음 듣기(🔊)는 폰에 들어 있는 **음성 엔진(TTS)** 을 씁니다. 여행 가는 나라 말의 음성이 폰에 없으면 소리가 나지 않으니, **출국 전에 한 번 확인**하세요.

**갤럭시**
1. 설정 → **일반** → **텍스트 음성 변환**(또는 **TTS**) → 선호하는 엔진(**Google 음성 인식 및 합성** 또는 **삼성 TTS**)
2. 엔진 옆 **⚙** → **음성 데이터 설치** → 필요한 언어(English, 日本語, 中文, Italiano, Français)를 내려받습니다.
3. 내려받아 두면 **인터넷 없이도** 발음을 들을 수 있습니다.

**아이폰**
1. 설정 → **손쉬운 사용** → **읽기 및 말하기** → **음성** → 필요한 언어를 골라 음성을 내려받습니다.
2. 소리가 안 나면 **무음 모드(옆면 스위치)** 를 끄고 음량을 올리세요.

그 밖에
- 자주 쓸 문장은 ⭐ **즐겨찾기**에 모아 두면 여행지에서 바로 찾을 수 있습니다.
- 위쪽 **천천히** 버튼을 누르면 느린 속도로 읽어 줍니다. 상대에게 폰 화면을 보여 주는 것도 좋은 방법입니다.

## 8. 새 버전 받기 (업데이트)

- 따로 할 일은 없습니다. 인터넷이 연결된 상태로 앱을 열면 새 버전을 자동으로 받습니다.
- 바로 반영되지 않으면 앱을 **완전히 닫았다가**(최근 앱 목록에서 위로 밀기) **다시 열어** 보세요.

## 9. 즐겨찾기·기록에 대해

- 즐겨찾기, 선택한 언어, 퀴즈 최고 기록은 **그 폰의 그 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 다른 폰이나 다른 브라우저에서 열면 처음부터 시작합니다.
- 브라우저에서 **쿠키 및 사이트 데이터**를 지우면 즐겨찾기도 지워집니다.

## 10. 앱 지우기

- **갤럭시:** 아이콘을 길게 누름 → **설치 삭제**(또는 **삭제**)
- **아이폰:** 아이콘을 길게 누름 → **앱 삭제** → **홈 화면에서 삭제**
- **PC:** 앱을 실행 → 오른쪽 위 `⋮` → **제거**

## 11. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 카카오톡에서 눌렀는데 Chrome으로 안 넘어감 | 위쪽 초록색 안내의 **[Chrome으로 열기]** 를 누르세요. 그래도 안 되면 카톡 브라우저 `⋮` → **다른 브라우저로 열기**. |
| 위쪽 설치 안내가 안 나옴 | 몇 초 기다리거나 화면을 한 번 눌러 보세요. 그래도 없으면 Chrome **`⋮` → 앱 설치(홈 화면에 추가)**. 예전에 ✕로 닫았다면 다시 나오지 않으니 메뉴를 쓰세요. |
| 설치했는데 아이콘이 안 보임 | 앱스 화면을 확인하거나, 설정 → 애플리케이션에서 "여행회화"를 찾아보세요. |
| 아이콘을 누르면 주소창이 있는 브라우저로 열림 | 바로가기로만 추가된 경우입니다. 지우고 Chrome의 **앱 설치**로 다시 설치하세요. |
| 🔊 소리가 안 남 | 미디어 음량을 올리고, [7번](#7-여행-전에-꼭-해-둘-것)처럼 그 언어의 음성 데이터를 설치하세요. "이 기기에 ○○어 음성이 없어…" 안내가 뜨면 음성 데이터가 없는 것입니다. |
| 비행기 모드에서 앱이 안 열림 | 설치 후 인터넷이 될 때 앱을 한 번도 열지 않은 경우입니다. 인터넷을 켜고 한 번 연 뒤 다시 해 보세요. |
| 일본어·중국어 글자 모양이 조금 다르게 보임 | 오프라인에서는 폰 기본 글꼴로 보일 수 있습니다. 내용은 같습니다. |

## 12. 사용 방법

- **위쪽 언어 선택:** 영어 / 일본어 / 중국어 / 이탈리아어 / 프랑스어
- **상황 칩:** 기본 표현, 공항·입국, 기내, 호텔, 식당·카페, 쇼핑, 교통, 길 묻기, 관광, 긴급 상황
- **검색:** 한국어(예: 화장실, 체크인)나 그 나라 말(예: toilet, トイレ, 洗手间, xishoujian)로 찾을 수 있습니다.
- **카드를 누르면** 발음을 들려주고, ⭐로 즐겨찾기에 담습니다.
- **퀴즈:** 한국어 뜻을 보고 알맞은 문장을 고릅니다. 전체·즐겨찾기·상황별로 범위를 고를 수 있습니다.

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체. 영어 `RAW`(상황\|영어\|발음\|뜻\|도움말)와 언어별 `LANG_RAW`가 **같은 순서 115줄**로 맞춰져 있음 |
| `manifest.json` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 캐시. 내용을 고치면 `VERSION`을 올릴 것 |
| `icons/` | 앱 아이콘 |
| `tools/check_data.py` | 문장 데이터 검사 (언어별 줄 수·칸 수·상황 이름) + `VERSION` 올리기 |
| `tools/make_icons.py` | 앱 아이콘(말풍선) 다시 만들기 (윈도우, `pip install pillow`) |

### 문장을 추가·수정할 때
1. 모든 언어에 **같은 위치**로 한 줄씩 넣습니다. 순서가 어긋나면 다른 언어의 문장이 엉뚱한 뜻에 붙습니다.
   - 영어 `RAW`: `상황|영어|한글 발음|뜻|도움말`
   - 일본어·이탈리아어·프랑스어: `문장|한글 발음`, 중국어: `문장|한글 발음|병음`
   - 즐겨찾기는 **영어 문장**을 열쇠로 저장하므로, 새 문장을 **아무 위치에나** 넣어도 기존 즐겨찾기가 밀리지 않습니다.
   - 이미 있는 **영어 문장을 고치면** 그 문장의 즐겨찾기는 풀립니다. (다른 언어 문장·발음·뜻을 고치는 것은 괜찮습니다)
   - 영어 문장이 두 번 들어가면 검사 도구가 오류로 알려 줍니다.
2. 저장소 맨 위 폴더에서 검사하고 `VERSION`을 올립니다. (추가 설치 필요 없음)
   ```bash
   python tools/check_data.py --bump
   ```
   - 줄 수가 언어마다 다르거나 칸 수가 틀리면 **오류를 알려 주고 멈춥니다.**
   - 특정 문장이 언어별로 잘 맞는지 보려면: `python tools/check_data.py --show 37` (0부터 셈)
3. GitHub에 올리면, 앱을 설치한 사람은 인터넷이 될 때 앱을 열면 자동으로 새 버전을 받습니다.

### 다른 PC에서 이어서 작업하기
```bash
git clone https://github.com/sinaboro/multi-language-talk
```
받은 폴더에서 위 순서대로 하면 됩니다. 필요한 것은 Python 3과 git뿐입니다.
